Web Access — GitHub Sign-in

The web interface requires a GitHub account, so every change it makes is recorded against a real person. Create an OAuth App at github.com/settings/developers and set its callback URL to http://localhost:7600/auth/github/callback.

Client ID

Public address

Reachable from other machines

Kyrios Chronos Scheduler Service

Install Kyrios Chronos as a Windows background service via NSSM. Tasks and backups keep running with the app closed and after you log off the server — the service runs headless as LocalSystem. Requires NSSM installed.
